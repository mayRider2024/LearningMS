Welcome to Frappe Learning

Easy to use, open source, Learning Management System

Demo Version

This is a frontend-only demo. To get the full LMS with backend functionality, install Docker Desktop and run the Docker setup.

📚 Structured Learning

Design courses with a 3-level hierarchy. Group lessons within chapters for better context.

🎥 Live Classes

Group learners into batches and create Zoom live classes right from the app.

📝 Quizzes & Assignments

Create interactive quizzes and assignments. Support for multiple choice and open-ended questions.

How to get the full version running:

1

Install Docker Desktop (Free)

Download from docker.com and install

2

Start Docker

Open Docker Desktop and wait for it to say "Running"

3

Run the setup

cd C:\Users\HP\OneDrive\Desktop\learningms\docker
docker-compose up -d

4

Access the LMS

Visit http://lms.localhost:8000/lms

Login: Administrator / admin
